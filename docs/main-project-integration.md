# Main Project Integration

## Role of the UFG NFT Layer

The UFG layer creates digital ownership, provenance, and lifecycle memory for the larger manufacturing ecosystem. It is cross-cutting: it does not sit after all eight layers, but records the evidence generated by each layer.

## Integration Points

| Source Layer | Input to NFT Layer | On-chain Record |
| --- | --- | --- |
| Physical Manufacturing | Machine ID, component ID, process ID | Product or Machine NFT mint event |
| IIoT Transformation | Edge gateway ID, protocol, signed payload hash | Process record hash |
| Data Acquisition | Sensor batch hash, time-series URI | Metadata update event |
| Blockchain Streaming | Stream checkpoint, transaction batch | Lifecycle process event |
| Prognosis and Diagnosis | AI result hash, model version, RUL score | Analytics record event |
| Ontology and Semantic | OWL/RDF URI, reasoning output hash | Semantic record event |
| Metaverse Validation | Simulation result URI, approval status | Validation record event |
| Closed-loop Execution | Applied parameter change hash | Final action record |

## Suggested Interface Contract

Each external team can submit data through an adapter that produces:

```json
{
  "tokenId": 1,
  "sourceLayer": "OntologySemantic",
  "eventType": "ReasoningResult",
  "artifactUri": "ipfs://bafy...",
  "artifactHash": "0x...",
  "submittedBy": "0x...",
  "timestamp": "2026-05-12T00:00:00.000Z"
}
```

The adapter then calls the appropriate contract function:

- `recordProcessStep`
- `recordMaintenance`
- `recordQuality`
- `recordSemanticResult`
- `recordMetaverseValidation`
- `updateMetadata`
