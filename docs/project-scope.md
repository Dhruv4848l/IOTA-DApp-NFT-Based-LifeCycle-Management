# Project Scope

## Title

**NFT-Based Lifecycle Management for Blockchain Supported Ontology and Semantic Integrated IIoT Enabled Manufacturing System**

## Problem Statement

Manufacturing lifecycle records are often fragmented across machine logs, inspection reports, maintenance sheets, supplier documents, and analytics systems. This makes provenance verification difficult, especially when the same component moves through multiple teams, machines, owners, and validation environments.

This project creates an NFT-based Digital Product Passport layer on IOTA EVM. Each manufactured asset, machine, maintenance event, quality certificate, skill certification, supply chain checkpoint, and carbon record can be represented as a verifiable NFT or NFT-linked lifecycle record.

## In Scope

- Digital identity for physical manufactured components.
- Lifecycle NFTs for product, machine, maintenance, quality, skill, supply chain, and carbon records.
- On-chain lifecycle stage tracking and audit events.
- Off-chain metadata stored through content-addressed IPFS-compatible URIs.
- Smart contract roles for foundry, OEM, MRO, quality, and regulator actors.
- Integration contract between analytics, ontology, metaverse validation, and physical execution layers.
- React dApp scaffold for project demonstration.

## Out of Scope for Current Prototype

- Production IIoT gateway implementation.
- Real machine control or PLC integration.
- Full ontology reasoner runtime.
- Full metaverse simulation engine.
- Smart contract audit certification.
- Regulated aerospace production deployment.

## Deliverables

- Solidity smart contract for IOTA EVM.
- Web3 dApp scaffold.
- Metadata schema and sample generator.
- Architecture and workflow diagrams.
- Integration documentation for the wider project.
