# Roadmap

## Phase 1: Demonstration Prototype

- Deploy DPP NFT contract to IOTA EVM testnet.
- Mint Product, Machine, Quality, Maintenance, Supply Chain, Skill, and Carbon NFT examples.
- Demonstrate lifecycle transition and metadata update.
- Show IPFS metadata hash verification.

## Phase 2: Integration Prototype

- Add adapters for analytics, ontology, and metaverse teams.
- Create event dashboard and provenance timeline.
- Add QR code lookup for physical-to-digital binding.
- Add sample turbine blade lifecycle walkthrough.

## Phase 3: Production Readiness

- Complete smart contract audit.
- Add multisig approval for decommissioning and critical quality releases.
- Add event indexer for full history.
- Add decentralized storage redundancy.
- Add regulator/auditor read-only portal.

## Phase 4: Research Extensions

- IOTA L1 Move migration feasibility study.
- Semantic NFT standards and RDF-native metadata.
- Carbon accounting and sustainability tokenization.
- AI-driven Remaining Useful Life updates with verifiable model lineage.
